# rubicsrealty.com (rebuild)

This is a full rebuild of the Rubics Realty website. The previous site was 3 hand-coded static pages. The audit that led to this rebuild is in `../research/AUDIT.md`, and the approved brief is in `../research/BRIEF.md`.

**Concept:** the lift lobby of a Mumbai Art Deco tower, with a brass floor indicator read against the building's section drawing. Every section of the site is a "floor" with a level code, and a brass readout in the header tracks the floor you are on. The signature feature is the **BeauMonté section explorer**, a lift you drag through Tower C to see what each level holds and the RERA carpet areas. See `PRODUCT.md` (strategy) and `DESIGN.md` (visual system).

## Stack
- Next.js 16 (App Router, Turbopack, Cache Components with Partial Prefetching), React 19, TypeScript
- Tailwind CSS v4 with OKLCH tokens in `src/app/globals.css`, shadcn base
- Motion (`motion/react`). Scrolling is native: no GSAP and no smooth-scroll library.
- Mona Sans (variable `wdth` + `wght`) via `next/font`
- zod for enquiry validation, shared by the client and the API

## Run
```bash
npm install
cp .env.example .env.local   # fill in delivery settings
npm run dev                  # http://localhost:3000
npm run build && npm start   # production
npm run lint
```

## Environment
See `.env.example`.
- **In production, the enquiry API returns an error unless Resend or a CRM webhook is configured.** This is deliberate, so leads are never lost silently.
- In development, leads are logged to the console instead.

## Verified (11 Nov 2026)
- `tsc --noEmit`, `npm run lint` and `next build` are clean. All 31 routes are static except the API.
- Every page was screenshotted at 1440px and 375px (`../research/final/`). There is no horizontal overflow and no console errors.
- Contrast was checked with `contrast.py` for every text/background token pair. The lowest ratio is 4.66 (BeauMonté accent on cream). The Lalbaug accent was lightened after it failed on navy.
- Enquiry API:
  - valid → 503 in production with no delivery configured (by design), 200 in dev
  - invalid → 422 with field errors
  - honeypot → 200, dropped
  - bad JSON → 400
- End-to-end browser test: explorer moved to level 30 → "Enquire" opened the form with Level 30 prefilled → an empty submit showed errors and moved focus to the first field → a filled submit showed the success state and the lead arrived in the log.
- Redirects: `/beaumonte.html`, `/media.html`, `/index.html` and `/media-detail.html` return 308 to the new routes. `/press/<unknown>` returns 404.

**Not verified:**
- Animations were checked only under reduced motion (screenshots). Header readout roll, hero line rise and reveal timing were not watched running.
- Real email delivery, because there are no Resend credentials.
- Lighthouse scores.
- Real devices (iOS Safari, Android Chrome).
